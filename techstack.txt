# StarWeaver Tech Stack

## Backend

### Framework & Server
- **FastAPI** (0.115.7) - Web framework for building APIs
- **Uvicorn** (0.25.0) - ASGI server
- **Python** (3.10+) - Programming language (upgraded from 3.9+ for better async support)

### Database
- **PostgreSQL** - Primary database (via Neon)
- **SQLAlchemy** - ORM with async support
- **asyncpg** - Async-friendly PostgreSQL driver (recommended to replace psycopg2-binary for better async performance)

### AI/ML & LLM
- **OpenAI API** (1.60.0) - Direct API calls for text generation (GPT models)
- **Custom Prompt & Memory Layer** - Custom implementation for:
  - Character consistency tracking
  - Panel-level generation control
  - Story memory assembly
  - Cost tracking
- ~~LangChain~~ (removed for MVP - adds abstraction without clear benefit for structured pipeline)

### Async Job Processing
- **Redis** - Message broker and caching layer
- **Celery** or **RQ** - Task queue system for handling:
  - Long-running LLM generation jobs
  - Image generation tasks
  - Export jobs (PDF generation, etc.)

### Object Storage
- **S3-compatible storage** (AWS S3, MinIO, or compatible service) - For storing:
  - Generated images
  - Exported PDFs
  - User-uploaded assets

### Configuration & Environment
- **python-dotenv** (1.0.1) - Environment variable management

### Containerization & Deployment
- **Docker** - Containerization
- **Docker Compose** - Multi-container orchestration (sufficient for MVP)
- ~~Kubernetes~~ (removed for MVP - adds operational complexity; consider post-MVP)

## Architecture

### Pattern
- **RESTful API** - Backend follows REST principles
- **Repository Pattern** - Data access layer abstraction
- **Service Layer** - Business logic separation
- **Async Job Queue** - Background processing for long-running tasks

### Key Design Decisions (MVP Focus)
- **Direct OpenAI API integration** - Full control over prompts, consistency, and costs
- **Custom memory assembly** - Tailored to novel-to-manga pipeline needs
- **Async-first architecture** - Python 3.10+ with asyncpg for database operations
- **Simplified stack** - Removed LangChain abstraction and Kubernetes complexity
- **Background job processing** - Celery/RQ for async generation tasks

### Project Structure
- Backend: FastAPI app with modular structure (API routes, services, repositories, schemas)
- Frontend: Next.js App Router structure
- Monorepo: Single repository with backend and frontend
